# Winver Femboy Edition for Linux

A Windows-style `winver` application for Linux.

## Installation

### Using curl

```bash
curl -fsSL https://raw.githubusercontent.com/CatKub/winver-femboy-edition-for-linux/main/setup.sh -o setup.sh
chmod +x setup.sh
./setup.sh
```

### If curl is not installed

```bash
wget -O setup.sh https://raw.githubusercontent.com/CatKub/winver-femboy-edition-for-linux/main/setup.sh
chmod +x setup.sh
./setup.sh
```

After installation, run:

```bash
winver
```

The application will also be available from your Linux application menu.

## Uninstall

```bash
rm -rf ~/.local/bin/winver
```
